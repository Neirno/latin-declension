# Латынь · III склонение

Откройте `index.html` в браузере. Страница, стили, разбор и учебный словарь находятся в одном файле и работают без интернета.

Введите `foramen` или словарную форму `cor, cordis n`. Если слова нет в подборке, введите именительный падеж, полный родительный падеж и род (`m`, `f`, `n`). Такой результат — разбор по правилам, а не словарная проверка.

Обозначения совпадают с [учебной схемой на референсе](https://dmitrygrachov.github.io/Libra/#how): А — основа на несколько согласных, Б — равносложные на `-is` или `-es`. Для `larynx`, `pharynx`, `meninx` и `phalanx` показана трактовка из § 101 учебника Чернявского; в других справочниках могут приводиться формы на `-ium`.

## Публикация на GitHub Pages

1. Создайте **отдельный** публичный репозиторий, например `latin-declension`.
2. Загрузите `index.html` в корень ветки `main`, не внутрь папки.
3. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, затем **main**, **/(root)** и **Save**.
4. После публикации откройте ссылку в **Settings → Pages**. Обычно это `https://<логин>.github.io/latin-declension/`.

Сервер, база данных и сборка не нужны. [Инструкция GitHub Pages](https://docs.github.com/en/pages/quickstart).

## Проверка логики

Из этой папки с Node.js 22: `node --test test.mjs`. Для публикации этот файл не нужен.
