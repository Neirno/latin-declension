# Латынь · III склонение

Откройте `index.html` в браузере или [страницу на GitHub Pages](https://neirno.github.io/latin-declension/). Страница, стили, правила и учебный словарь находятся в одном файле.

Введите `foramen` или словарную форму `cor, cordis n`. Если введённого слова нет в подборке, страница ищет точную латинскую запись существительного в [Wiktionary](https://en.wiktionary.org/) через [MediaWiki Action API](https://www.mediawiki.org/wiki/API:Parsing_wikitext). В запрос уходит только это слово; токен и аккаунт не нужны. Источник указывается под результатом.

Если внешняя запись отсутствует или сервис недоступен, введите именительный падеж, полный родительный падеж и род (`m`, `f`, `n`). Для внешней записи и ручного ввода тип вычисляется по учебным правилам: редкие исключения, которых нет во встроенном словаре, могут потребовать проверки.

Обозначения совпадают с [учебной схемой на референсе](https://dmitrygrachov.github.io/Libra/#how): А — основа на несколько согласных, Б — равносложные на `-is` или `-es`. Исключения по роду показаны отдельно от исключений по склонению. Например, `cor, cordis n` — смешанный А, хотя `cor` входит в список исключений по роду.

### Учебники

- М. А. Бондаренко, [«Латинский язык и основы медицинской терминологии»](https://tsutula.bookonlime.ru/reader/book/2014042916543273126900001395), ТулГУ, 2005. С. 31–41 — разновидности и исключения по роду, с. 51–52 — Gen. pl. на `-um` у `larynx` и аналогичных слов, `vas`, `fauces`, `ile`; с. 81–84 — клинические термины; с. 141–142 — особые Acc. и Abl. sing.; с. 235 и далее — анатомический словарь.
- М. Н. Чернявский, Е. П. Тверковкина и др., «Латинский язык и основы медицинской терминологии», 2-е изд., Минск, 1989, ISBN 5-339-00184-9. § 118 и с. 125 — Gen. pl.; с. 307 и далее — латинско-русский словарь.

Для греческих слов на `-nx/-ngis` здесь принята форма Gen. pl. на `-um` по Бондаренко; в других справочниках встречаются формы на `-ium`.

## Публикация на GitHub Pages

1. Создайте **отдельный** публичный репозиторий, например `latin-declension`.
2. Загрузите `index.html` в корень ветки `main`, не внутрь папки.
3. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, затем **main**, **/(root)** и **Save**.
4. После публикации откройте ссылку в **Settings → Pages**. Обычно это `https://<логин>.github.io/latin-declension/`.

Сервер, база данных и сборка не нужны. [Инструкция GitHub Pages](https://docs.github.com/en/pages/quickstart).
